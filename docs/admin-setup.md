# Πρώτη εγκατάσταση διαχειριστή BarberBook

Η σελίδα διαχείρισης βρίσκεται στη διεύθυνση `/admin`. Δεν υπάρχει φόρμα δημόσιας εγγραφής. Ο λογαριασμός δημιουργείται μία φορά από το Supabase Dashboard και εξουσιοδοτείται με το μοναδικό Supabase Auth User ID.

## Για το υπάρχον BarberBook project

Η βάση έχει ήδη ρυθμιστεί με τον πίνακα διαχειριστή, τους κανόνες πρόσβασης και τον πίνακα εβδομαδιαίου ωραρίου. Ακολούθησε τα παρακάτω βήματα.

1. Άνοιξε το [Supabase Dashboard](https://supabase.com/dashboard) και επίλεξε το project του BarberBook.
2. Από το αριστερό μενού άνοιξε **Authentication → Users**.
3. Πάτησε **Add user → Create new user**. Συμπλήρωσε το email και έναν ισχυρό κωδικό που θα γνωρίζει μόνο ο ιδιοκτήτης. Ενεργοποίησε την επιβεβαίωση email αν εμφανίζεται σχετική επιλογή και δημιούργησε τον χρήστη.
4. Στη λίστα χρηστών άνοιξε τον νέο χρήστη και αντίγραψε το **User UID**. Είναι το μοναδικό αναγνωριστικό του λογαριασμού.
5. Άνοιξε **SQL Editor → New query** και εκτέλεσε την παρακάτω εντολή, αντικαθιστώντας μόνο το ενδεικτικό κείμενο με το User UID που αντέγραψες:

```sql
update private.admin_config
set admin_user_id = 'PASTE-THE-USER-UID-HERE'
where singleton = true;
```

6. Για επιβεβαίωση, εκτέλεσε:

```sql
select admin_user_id from private.admin_config where singleton = true;
```

   Το αποτέλεσμα πρέπει να είναι το ίδιο User UID.
7. Στο Supabase άνοιξε **Authentication → Settings** και απενεργοποίησε το **Allow new users to sign up** (αν είναι ενεργό). Η δημιουργία του ιδιοκτήτη γίνεται από το Dashboard, όχι από τη δημόσια εφαρμογή.
8. Άνοιξε την εφαρμογή σου και πρόσθεσε `/admin` στο τέλος της διεύθυνσης. Συνδέσου με το email και τον κωδικό που δημιούργησες.

## Για νέο αντίγραφο του βιβλίου / νέο Supabase project

1. Δημιούργησε το Supabase project και ρύθμισε τα δύο δημόσια στοιχεία σύνδεσης της εφαρμογής στις μεταβλητές περιβάλλοντος του hosting: `NEXT_PUBLIC_SUPABASE_URL` και `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`. Μόνο το publishable key χρησιμοποιείται στον browser.
2. Άνοιξε το αρχείο [`supabase/setup/admin-dashboard.sql`](../supabase/setup/admin-dashboard.sql), αντέγραψε όλο το περιεχόμενό του και εκτέλεσέ το στο **SQL Editor** του νέου project, αφού έχει δημιουργηθεί ο βασικός πίνακας `services`.
3. Ακολούθησε τα βήματα 2–8 της προηγούμενης ενότητας για να δημιουργήσεις και να εξουσιοδοτήσεις τον ιδιοκτήτη.

## Έλεγχος ότι λειτουργεί

- Χωρίς σύνδεση, το `/admin` εμφανίζει μόνο τη φόρμα σύνδεσης.
- Με λογαριασμό που δεν έχει εξουσιοδοτηθεί, η εφαρμογή εμφανίζει μήνυμα περιορισμένης πρόσβασης.
- Με τον εξουσιοδοτημένο λογαριασμό, μπορείς να προσθέσεις/αλλάξεις υπηρεσίες και να αποθηκεύσεις το εβδομαδιαίο ωράριο.
- Μετά την αποθήκευση, ανανέωσε τη σελίδα. Οι τιμές πρέπει να παραμένουν ίδιες. Στη δημόσια σελίδα κρατήσεων εμφανίζονται μόνο οι ενεργές υπηρεσίες.
- Η απενεργοποίηση κρύβει μια υπηρεσία από τις νέες κρατήσεις· δεν διαγράφει την υπηρεσία ούτε τις παλιές κρατήσεις της.

**Σημαντικό:** Η εφαρμογή δεν δημιουργεί ακόμη πραγματικές κρατήσεις. Το επόμενο στάδιο θα συνδέσει το αποθηκευμένο ωράριο με τον υπολογισμό διαθέσιμων ωρών.
